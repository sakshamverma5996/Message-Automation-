# Bulk Marketing Hub • 3-in-1 Suite (WhatsApp DM • Group Member Add • Gmail) 🚀

A free, native Windows desktop application featuring 3 complete marketing tools with **ZERO paid API subscriptions**:

1. **📱 WhatsApp Direct Message**: Send personalized 1-on-1 WhatsApp messages in bulk without page reloads.
2. **👥 WhatsApp Group Member Add**: Supervised, one-at-a-time direct addition through the visible WhatsApp Web UI.
3. **📧 Gmail Bulk Mailer**: Send personalized bulk emails via free Gmail SMTP with attachment support.

---

## 🌟 1. WhatsApp Group Member Add

### How It Works:
1. Select the **`[👥 Group Member Add]`** tab and enter the exact group title.
2. Load the phone list from CSV or use **📋 Paste**.
3. Confirm that the contacts agreed to join and click **▶ Start Direct Add**.
4. Log in to WhatsApp Web in the visible browser and open the exact target group.
5. Review each WhatsApp contact match in the app and confirm it before the Add action.
6. Export the result or not-added CSV from the log panel.

> [!NOTE]
> Direct addition is performed through WhatsApp Web's changing UI, not an official direct-add API. The UI must allow you to add the person; privacy restrictions stop the run and are never bypassed. The app does not send fallback invitations. Keep the browser visible and only add people who consented.

## 🌟 2. WhatsApp Direct Message (1-on-1 Bulk)

- **Zero-Reload In-Session Dispatch**: WhatsApp Web opens and authenticates only once. Subsequent messages are sent using in-app native search without refreshing the browser tab.

## 🌟 3. Gmail Bulk Mailer (Free SMTP)

- **Free Gmail SMTP**: Sends genuine emails directly through Google's free SMTP server (`smtp.gmail.com`).
- **Zero API Costs**: No SendGrid, Mailchimp, or AWS SES fees.
- **Credentials Setup**: Enter your Gmail address and 16-character **Google App Password**.
- **Test Connection**: "🧪 Test Connection" button to verify your credentials with 1 click.
- **Email Composer**: Personalized Subject line + message body with dynamic tags (`+ {name}`, `+ {email}`, `+ {note}`).
- **Attachments Support**: Attach PDFs, images, or documents via `📎 Add Attachment`.
- **Recipient Management**: Import CSV or use Quick Paste (`email, name, note`).

## 🔑 How to Get a Free Google App Password (Takes 30 Seconds)

1. Go to your Google Account: [myaccount.google.com](https://myaccount.google.com).
2. Click **Security** on the left menu.
3. Turn on **2-Step Verification** (if not already enabled).
4. In the top search bar, search for **App passwords**.
5. Type any name (e.g. `Bulk Mailer`) and click **Create**.
6. Google will give you a **16-character password** (e.g. `abcd efgh ijkl mnop`).
7. Enter your Gmail and this 16-character password in the app!
